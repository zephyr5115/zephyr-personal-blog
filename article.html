HTML5 入门笔记：从网页结构到常用功能

学习前端开发，首先需要理解网页是怎样组织起来的。一篇文章的标题、导航、图片、视频和表单，都需要通过 HTML 描述。这篇笔记从基础文档结构出发，介绍 HTML5 的常用能力，并通过简单示例说明它们的使用方式。

Zephyr发布于 CSDN · 本站收录全文

学习前端开发，首先需要理解网页是怎样组织起来的。一篇文章的标题、导航、图片、视频和表单，都需要通过 HTML 描述。
这篇笔记从基础文档结构出发，介绍 HTML5 的常用能力，并通过简单示例说明它们的使用方式。

一、认识 HTML 与 HTML5

HTML 的全称是 HyperText Markup Language，中文称为“超文本标记语言”。它通过标签描述网页内容的结构与含义。

例如：

<h1>我的第一篇博客</h1>
<p>这里记录我的前端学习过程。</p>

其中，<h1> 表示一级标题，<p> 表示段落。浏览器读取这些标记后，就能组织和展示页面内容。

“HTML5”通常用来指代 HTML 的一次重要发展，以及围绕它形成的一系列现代网页能力。现在学习 HTML，应以持续更新的 **HTML Living Standard（HTML 现行标准）**为准。可以在 WHATWG 官方标准中了解它的发展方式。

开发网页时，通常需要三种技术共同配合：

技术主要作用例子
HTML描述内容和结构标题、文章、图片、表单
CSS控制页面外观和布局颜色、间距、字体、动画
JavaScript实现交互与逻辑按钮响应、内容筛选、主题切换

因此，学习 HTML 的重点，是先把内容放到正确的位置，并为它选择合适的标签。

二、写出一个基础 HTML 页面

下面是一份可以直接保存并打开的 HTML 文档：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Zephyr 的学习笔记</title>
</head>
<body>
    <h1>你好，HTML！</h1>
    <p>这是我的第一个网页。</p>
</body>
</html>

将代码保存为 index.html，然后使用浏览器打开，就能看到页面。

这份代码包含几个重要部分：

  • <!DOCTYPE html>：文档类型声明，放在文档开头，帮助浏览器使用标准模式解析页面。
  • <html>：整个 HTML 文档的根元素。
  • lang="zh-CN"：说明页面主要使用简体中文。
  • <head>：保存编码、页面标题等信息。
  • <meta charset="UTF-8">：声明字符编码，帮助中文内容正确显示。
  • <title>：设置浏览器标签页中的标题。
  • <body>：包含页面中实际展示的内容。

视口设置有助于页面在移动设备上正确显示，但具体的手机布局仍然需要通过 CSS 实现。

三、用语义化标签组织内容

语义化，就是让标签能够表达内容的用途。例如，导航区域使用 <nav>，独立文章使用 <article>。

合理选择标签，有助于开发者理解代码，也能帮助辅助技术识别页面结构。相关说明可以参考 MDN：语义。

常用的语义化标签包括：

标签用途
<header>页面或某个内容区域的介绍、标题等头部内容
<nav>主要导航链接
<main>页面主体内容
<article>可以独立理解的内容，例如博客文章
<section>有共同主题的内容分区，通常包含标题
<aside>与主要内容相关的补充信息
<footer>页面或内容区域的页脚
<figure>图片、图表等独立内容
<figcaption>对应 <figure> 的说明
<time>日期或时间

一个博客页面可以这样组织：

<header>
    <h1>Zephyr 的博客</h1>

    <nav aria-label="主要导航">
        <a href="index.html">首页</a>
        <a href="posts.html">文章</a>
        <a href="about.html">关于我</a>
    </nav>
</header>

<main>
    <article>
        <h2>认识 HTML5</h2>
        <p>发布于 <time datetime="2026-10-25">2026年10月25日</time></p>
        <p>这里是文章正文。</p>
    </article>
</main>

<footer>
    <p>© 2026 Zephyr</p>
</footer>

需要区分的是：<head> 保存文档信息，<header> 则组织页面中的头部内容。

四、通过链接和图片丰富页面

超链接与图片是网页中最常见的内容。

<a href="about.html">了解更多关于我的信息</a>

<img src="images/example.png"
     alt="一个三行三列的图片九宫格">

这里的三个属性分别表示：

  • href：点击链接后前往的地址。
  • src：需要加载的图片地址。
  • alt：图片的文字说明。

也可以把图片放进超链接中，让图片成为一个可点击的入口：

<a href="images/example.png"
   target="_blank"
   rel="noopener">
    <img src="images/example.png"
         alt="打开九宫格原图">
</a>

对于本地练习，建议将图片放进项目文件夹，并使用相对路径引用。移动或提交作业时，要把 HTML 和图片文件一起保存。

五、在网页中播放视频与音频

HTML 提供了 <video> 和 <audio>，可以将媒体内容嵌入网页。

下面是一个视频示例：

<video controls width="480">
    <source src="media/demo.mp4" type="video/mp4">
    你的浏览器无法播放此视频。
</video>

其中：

  • controls：显示浏览器提供的播放控件。
  • width：设置显示宽度。
  • <source>：指定媒体文件地址和类型。

实际播放效果还与浏览器支持的媒体格式、编解码器有关，具体可以查阅 MDN：video 元素。

音频的写法也很简单：

<audio controls>
    <source src="media/music.mp3" type="audio/mpeg">
    你的浏览器无法播放此音频。
</audio>

使用这些代码前，需要准备对应的媒体文件，并确认文件路径正确。

六、使用更合适的表单控件

表单用于收集用户输入。为不同的数据选择合适的输入类型，可以改善填写体验，并使用浏览器提供的基础验证能力。

常见类型包括：

类型用途
text普通文本
email邮箱地址
url网址
date日期
time时间
datetime-local本地日期与时间
number数字
range范围选择
search搜索内容

例如：

<form>
    <p>
        <label for="email">邮箱：</label>
        <input id="email"
               name="email"
               type="email"
               required>
    </p>

    <p>
        <label for="birthday">生日：</label>
        <input id="birthday"
               name="birthday"
               type="date">
    </p>

    <button type="submit">提交</button>
</form>

required 表示必填。提交时，浏览器会检查邮箱是否为空，以及是否符合邮箱输入类型的基本格式要求。

这只能完成基础检查；正式项目仍需要在服务端验证收到的数据。各种输入类型的具体行为可以参考 MDN：input 元素。

另外，日期输入使用的是 type="date" 等实际类型，并没有通用的 type="calendar"。

七、认识 Canvas 与浏览器存储

1. 使用 Canvas 绘制图形

<canvas> 提供绘图区域，具体的绘制操作通常由 JavaScript 完成。

<canvas id="drawing" width="300" height="180">
    你的浏览器不支持 Canvas。
</canvas>

<script>
    const canvas = document.querySelector("#drawing");
    const context = canvas.getContext("2d");

    if (context) {
        context.fillStyle = "#586bff";
        context.fillRect(40, 40, 160, 90);
    }
</script>

这段代码会绘制一个蓝色矩形。

Canvas 可以用于图表、绘画和游戏等场景；三维绘制则可以使用 Canvas 上的 WebGL 上下文。更多内容可以参考 MDN：Canvas API。

2. 保存简单的浏览器侧数据

Web Storage 提供了两种常见存储方式：

  • localStorage：通常可以跨浏览器会话保留数据。
  • sessionStorage：数据与当前页面会话关联。

它们通过 JavaScript 使用，适合保存一些简单的键值数据，例如主题偏好：

// 保存主题偏好
localStorage.setItem("theme", "dark");

// 读取主题偏好
const theme = localStorage.getItem("theme");

console.log(theme);

存储值按字符串处理。实际项目中，还需要考虑浏览器权限、存储限制及异常处理。可以参考 MDN：Web Storage API。

浏览器侧存储可以帮助保存数据；完整的离线访问，还需要缓存策略等额外设计。

八、阅读旧教程时需要注意什么

旧教程可以帮助理解基础概念，但部分内容需要结合现行标准重新判断。

首先，HTML 标准仍在持续更新。 学习时可以保留“HTML5”这个常见称呼，同时关注现行标准和具体功能的文档。

其次，CSS 动画、三维变换等属于相关技术。 它们可以与 HTML 配合使用，学习时应分别理解 HTML、CSS 和 JavaScript 的职责。

再次，一些早期技术已经过时。 例如 Web SQL 已被弃用，学习浏览器存储时可以关注 Web Storage 和 IndexedDB。相关历史与替代方向可参考 Chrome 官方的 Web SQL 弃用说明。

对于标签与兼容性，也可以记住这些原则：

  • 字体、颜色、居中等外观优先交给 CSS 控制。
  • 新项目使用现行标准中的元素，不照搬 <font>、<center>、<command> 等旧标签。
  • 根据项目实际支持的浏览器检查兼容性，避免直接套用围绕 IE9 编写的旧结论。

九、我的学习思路

学习 HTML，可以按照下面的顺序逐步练习：

  1. 写出完整的基础文档。
  2. 使用标题、段落、列表、链接和图片组织内容。
  3. 用语义化标签搭建博客结构。
  4. 添加表单、音频和视频。
  5. 再结合 CSS 改善布局，使用 JavaScript 增加交互。

对初学者来说，先完成一个结构清楚的小页面，再逐步补充功能，是比较容易坚持的学习方式。

HTML 标签的价值，在于准确表达内容。理解每个元素适合放在哪里，比一次记住很多标签更有用。
